# Netflix User Behaviour Analysis

## About the Project
This project focuses on analyzing Netflix user behaviour to understand viewing patterns, user engagement, and subscription churn.

## Objectives
- Analyze Netflix user behaviour and viewing patterns.
- Perform exploratory data analysis (EDA).
- Apply statistical techniques to identify trends and patterns.
- Build machine learning models to analyze user churn.
- Evaluate model performance using appropriate metrics.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/samikshawani1/Netflix_User_behaviour.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Netflix_User_behaviour
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application using the command appropriate for the project.
